# Block Breakerz - 遊び方


## 必要なライブラリ
以下のライブラリを使用していますので、実行前にインストールをお願いします。

- pip install pygame
- pip install pillow


---


## 遊び方
１.解凍した「Block_Breakerz」のフォルダをそのままVSCode上にドラッグ&ドロップします。
２.必要なライブラリをインストールします。
３.Main.pyを実行します。


---


## ルール
- ボールをパドルを操作しながら跳ね返し、画面に配置されているブロックを壊します。
- 各ステージに設けられているスコアを達成するとクリアとなり、次のステージに進むことができます。


---


## 操作方法
- スペースキー：ゲーム開始
- 左右の矢印キー：パドルの操作
- Pキー：一時停止
- Rキー：リトライ
- Cキー：クレジット表示
- Qキー：やめる
